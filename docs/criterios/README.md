# Registro de criterios de interpretación

Una ficha por ambigüedad, con la plantilla [`plantillas/criterio.md`](../plantillas/criterio.md).
Un criterio no es norma: la IA que use el corpus debe presentarlo como
interpretación, con su motivo.

| ID | Ambigüedad | Criterio | Confianza | Estado |
|---|---|---|---|---|
| [CRI-001](lista-caducada.md) | Qué hacer con una lista pasada su `NextUpdate` | Se rechaza | alta | vigente |
| [CRI-002](fijar-firmante-de-la-lista.md) | Cómo autenticar al firmante de la lista | Fijar el certificado exacto, configurable | media | vigente |
| [CRI-003](sin-lista-no-se-valida.md) | Verificación sin lista de confianza configurada | Es un error, no un aprobado | alta | vigente |
